# Credit Card Fraud Detection

## Project Overview
This project detects fraudulent credit card transactions using Machine Learning.

## Technologies Used
- Python
- Pandas
- Scikit-learn

## Dataset
Dataset Source: TensorFlow Credit Card Fraud Dataset

## Machine Learning Workflow
1. Data Loading
2. Data Preprocessing
3. Train-Test Split
4. Logistic Regression Model
5. Prediction
6. Accuracy Evaluation

## Result
The model achieved very high accuracy in detecting fraudulent transactions.
